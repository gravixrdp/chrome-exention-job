## File Descriptions

### Core Configuration

**manifest.json**
- Chrome Extension Manifest V3
- Defines permissions, content scripts, background worker
- OAuth2 configuration for Google Sheets
- Extension metadata

**package.json**
- NPM dependencies (React, Vite)
- Build scripts
- Project metadata

**vite.config.js**
- Vite bundler configuration
- Entry points for popup, background, content scripts
- Build optimization settings

**post-build.js**
- Copies manifest, assets, and static files to dist
- Runs after Vite build

### Background Script

**background.js**
- Service worker (Manifest V3)
- Handles:
  - Job detection notifications
  - Duplicate checking
  - Application saving
  - Google OAuth flow
  - Inactivity timer
  - Follow-up alarms

## Data Flow

### Job Detection Flow
```
Job Page Load
  → Content Script Detects Job
    → Extracts Data
      → Sends to Background
        → Background Checks Filters
          → Shows Notification (if match)
            → User Opens Extension
              → Calculates Match Score
                → Checks Duplicates
                  → Shows Result
```

### Autofill Flow
```
User Clicks Autofill
  → Extension Gets Profile & Q&A
    → Sends to Content Script
      → AutofillEngine Processes Form
        → Matches Fields
          → Fills Values
            → Highlights Fields
              → Shows Summary
                → User Reviews & Submits
```

### Application Save Flow
```
User Saves Application
  → Data Sent to Background
    → Background Saves to Local Storage
      → Tries to Sync to Google Sheets
        → Creates Notification
          → Updates Dashboard Stats
```

## Storage Schema

### chrome.storage.local
```javascript
{
  // Authentication
  passwordHash: "sha256_hash",
  isSetup: true,
  
  // User Data
  profile: { fullName, email, phone, skills, ... },
  resumes: [{ id, name, isDefault, uploadedAt }, ...],
  qaBank: [{ question, answer }, ...],
  filters: { keywords, locations, minSalary, ... },
  
  // Applications
  applications: [{
    id, date, platform, title, company,
    location, jobUrl, matchScore, status,
    resumeUsed, notes, followUpDate
  }, ...],
  
  // Settings
  settings: {
    autoLockEnabled, inactivityTimeout,
    notifications, minMatchScore
  },
  
  // Integrations
  googleSheets: {
    connected, spreadsheetId,
    spreadsheetName, connectedAt
  },
  aiConfig: {
    enabled, apiKey
  }
}
```

### chrome.storage.session
```javascript
{
  locked: true/false,
  currentJob: { title, company, ... }
}
```

## API Integration

### Google Sheets API
- Endpoint: `https://sheets.googleapis.com/v4/spreadsheets/`
- Authentication: OAuth 2.0
- Scopes: `https://www.googleapis.com/auth/spreadsheets`
- Operations:
  - Read spreadsheet metadata
  - Append rows
  - Query for duplicates

### OpenRouter API
- Endpoint: `https://openrouter.ai/api/v1/chat/completions`
- Authentication: Bearer token
- Model: `openai/gpt-3.5-turbo`
- Operations:
  - Generate text completions
  - Cover letters, improvements, summaries

## Security Measures

1. **Password Hashing**: SHA-256, never plain text
2. **Auto-lock**: Inactivity timeout
3. **Local Storage**: All data kept locally
4. **OAuth**: Standard Google OAuth 2.0
5. **Minimal Permissions**: Only necessary permissions
6. **No Tracking**: No analytics or data collection
7. **API Keys**: Stored locally, user-provided

## Browser Permissions

### Required Permissions
- `storage`: Store user data locally
- `notifications`: Show job match notifications
- `alarms`: Follow-up reminders
- `identity`: Google OAuth
- `activeTab`: Access current tab for job detection
- `scripting`: Inject content scripts

### Host Permissions
- `https://www.linkedin.com/*`: LinkedIn job detection
- `https://www.indeed.com/*`: Indeed job detection
- `https://www.naukri.com/*`: Naukri job detection
- `https://sheets.googleapis.com/*`: Google Sheets API
- `https://openrouter.ai/*`: AI API

## Performance Considerations

- **Lightweight Background Worker**: Minimal memory footprint
- **Efficient Storage**: Indexed by ID for fast lookups
- **Lazy Loading**: Components load on demand
- **Debounced Actions**: Prevent excessive API calls
- **Local Caching**: Reduce redundant API requests
